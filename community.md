# Community

Vianium runs a small community space around
[`vianium-localsend`](https://github.com/vianium/vianium-localsend), the
LocalSend client for Windows Phone 8.1 and Windows 10 Mobile. The space
exists for real-time conversation, user support and beta coordination.

## Where to find us

| Need | Channel |
|---|---|
| Real-time chat, user support, beta testing | Discord — invite link in the `vianium-localsend` README |
| Bug reports | GitHub issues in the respective repository |
| Design conversations | GitHub Discussions in [`vianium-docs`](https://github.com/vianium/vianium-docs/discussions) |
| Security disclosures | See [SECURITY.md](SECURITY.md) — do **not** post in Discord |
| Commercial licensing inquiries | `hello@angelcareaga.com` |

## Operating language

The primary language is **English**. Maintainers reply in English by
default.

## Server structure

### Roles

| Role | Assignment | Purpose |
|---|---|---|
| Founder | manual | Angel Careaga |
| Maintainer | manual | Co-maintainers (when applicable) |
| Beta Tester | manual | Access to pre-release builds via the beta channel |
| Bug Hunter | manual | Awarded to members who file confirmed bugs |
| Member | default | All other members |

Device roles (WP8.1 owner, W10M owner) are self-assigned via reaction
roles in the welcome channel.

### Channels

- `#welcome` — rules, links, reaction roles, permanent invite.
- `#announcements` — releases and news; read-only for members.
- `#governance` — discussion preceding new ADRs in `vianium-docs`.
- `#general` — general discussion.
- `#showcase` — screenshots and videos running on real hardware.
- `#localsend-general` — usage, questions, feedback.
- `#localsend-bugs` — forum channel. Tags: `discovery`, `transfer`, `pairing`, `firewall`.
- `#localsend-dev` — contributors and design discussion.
- `#off-topic` — anything else, within the Code of Conduct.
- Private: `#maintainers`, `#security-disclosures` (per [SECURITY.md](SECURITY.md)), `#beta-channel`.

## Channel guidelines

- Bugs belong in `#localsend-bugs`, not in `#localsend-general`.
- `#localsend-dev` is for contributors discussing implementation.
- `#beta-channel` is the only authorised place to share pre-release
  builds. Re-distributing beta builds outside the server is not permitted.

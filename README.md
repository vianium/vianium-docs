[Vianium](https://github.com/vianium) project, which brings
[LocalSend](https://github.com/vianium/vianium-localsend) to Windows
Phone 8.1 and Windows 10 Mobile.

## Architecture Decision Records

ADRs capture significant design decisions. Per-repo decisions live in
each repository's own `docs/adr/` folder when needed.

- [0001 — Multi-repo over monorepo](adr/0001-multi-repo.md)
- [0002 — Dual licensing](adr/0002-dual-licensing.md)

New ADRs follow the format `NNNN-short-slug.md` and are numbered
sequentially.
